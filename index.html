Meus Projetos

EasyRefund

O EasyRefund é uma aplicação web desenvolvida para centralizar e automatizar a gestão de pedidos de reembolso da Fortes Engenharia. O sistema foi criado durante o Hack-27 a partir de um desafio real da empresa, substituindo processos manuais e fragmentados por um fluxo digital de submissão, análise e acompanhamento das solicitações. A plataforma permite que funcionários enviem pedidos com comprovantes, acompanhem o status das solicitações e que usuários administrativos analisem, aprovem ou recusem os reembolsos. O sistema também oferece histórico e rastreabilidade dos processos. Tecnologias usadas: HTML,CSS, REACT, NODE, BYCRPTY, JWT e MYSQL.

Organfy

O Organfy surgiu a partir da necessidade de melhorar meu próprio controle financeiro. A aplicação permite acompanhar despesas, cadastrar metas, registrar depósitos e visualizar de forma organizada para onde o dinheiro está sendo destinado. Tecnologias usadas: HTML, CSS, REACT, NODE, BYCRPT, JWT e POSTGRESQL

DataMerge

O DataMerge surgiu a partir de uma necessidade que identifiquei no ambiente de trabalho: tornar mais rápido e simples o processo de cruzamento de dados entre diferentes planilhas. A aplicação permite que o usuário envie duas tabelas nos formatos CSV, XLS ou XLSX e realize a junção das informações a partir da coluna CODPROD. O projeto foi desenvolvido como uma alternativa mais simples ao uso de fórmulas como PROCV e PROCX, facilitando o processo para usuários que não possuem conhecimento avançado em Excel. Dessa forma, o DataMerge automatiza uma tarefa que, dependendo da quantidade e complexidade dos dados, poderia consumir horas ou até dias de trabalho manual.
